1. **`Comet.Account` (سيرفر الحسابات - بورت `9960`):**

2. **`Comet.Game` (سيرفر العالم واللعب - بورت `5816`):**
   هو قلب اللعبة بالكامل: يستقبل اللاعب، يحمّل شخصيته من قاعدة بيانات `comet.game`، يدخله الخريطة، ويعرضه للاعبين المحيطين، ويشغّل المشي والنط والبوابات والشات والأوامر.

* **كيف تعدّل مكان بداية اللاعب الجديد أو الفلوس المبدئية؟**

### 3. كلاس اللاعب ومعادلات الدم والمانا واللفلفة (`Character.cs`)
* **المسار:** `src/Comet.Game/States/Character.cs`
* **وظيفته:** يمثّل اللاعب الحي داخل اللعبة، ويحتوي على كل خصائصه ومعادلاته الرسمية:
  * **شكل الشخصية (`Mesh`):** يحسب الشكل بمعادلة كونكر `Body + (Avatar * 10000)`، وعند الموت يحوله تلقائياً لشكل الشبح (`98` للولد و `99` للبنت).
  * **معادلة الدم القصوى (`MaxLife`):** تحسب `(Strength * 3) + (Agility * 3) + (Spirit * 3) + (Vitality * 24)`، وتضرب الناتج في بونص التروجان (`1.05` حتى `1.15` للتروجان ماستر).
  * **معادلة المانا القصوى (`MaxMana`):** تضرب `Spirit * 5`، وللتاويست تضاعفها رسمياً حتى `6` أضعاف (`30` مانا لكل نقطة Spirit للتاويست الماستر).
  * **استرجاع الـ Stamina وتناقص الـ PK:** في دالة `OnTimerAsync()`، كل ثانيتين تزيد الـ Stamina (`+5` واقف، `+10` جالس)، وكل 6 دقائق تنقص نقاط الـ PK نقطة واحدة (وفي السجن خريطة `6000` كل 3 دقائق).
* **كيف تعدّل سرعة شحن الـ Stamina أو أقصى لفل؟**
  * **لتعديل شحن الـ Stamina:** افتح `src/Comet.Game/States/Character.cs` وانزل إلى آخر الملف عند دالة `OnTimerAsync`:
    ```csharp
    int bonus = this.Action switch
    {
        EntityAction.Sit or EntityAction.Lie => 10, // <-- مقدار الزيادة أثناء الجلوس
        _ => 5                                      // <-- مقدار الزيادة أثناء الوقوف
    };
    ```
  * **لتعديل أقصى لفل في السيرفر (حالياً `140`):** افتح `src/Comet.Game/World/Managers/ExperienceManager.cs` وعدّل السطر:
    ```csharp
    public const byte MAX_LEVEL = 140;
    ```
