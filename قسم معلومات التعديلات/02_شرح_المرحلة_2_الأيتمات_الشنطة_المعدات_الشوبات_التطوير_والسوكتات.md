## أولاً: ما الذي أضفناه في المرحلة الثانية؟ (الصورة الكبيرة)

أصبح السيرفر الآن يمتلك **منظومة الأيتمات والمعدات الرسمية الكاملة لباتش 5187** وتشمل:
1. **قارئ ذكي مزدوج للأيتمات والشوبات (`ItemManager.cs`):** يفك تشفير `ini/itemtype.dat` (`0x2537`) ويقرأ `ini/ItemAdd.ini` و `ini/Shop.dat` مباشرة من فولدر كلينت 5187 تلقائياً بدون الحاجة لأي برنامج خارجي، وأي تعديل تضعه في قاعدة البيانات MySQL يغلب ملف الكلينت تلقائياً!
2. **الشنطة والمعدات والبنوك (`UserPackage.cs`):**
   * شنطة 40 خانة مع دعم تكديس وتقسيم الأيتمات (`Split / Combine`).
   * 18 خانة لبس تشمل كافة كلاسات 5187 (بما فيها لبس النينجا لـ 2 كاتانا، القوس والأسهم للأرشر، الدرع للواريور والريبورن، المروحة والبرج والكروب والحصان والجيرمنت).
   * البنوك والمخازن في كل المدن + فتح بنوك الـ VIP عن بُعد حسب لفل الـ VIP + إيداع وسحب الفضة من البنك.
3. **إظهار اللبس والحصان ومعاينة اللاعبين (`MsgPlayer.cs` & `MsgAction.cs`):** بمجرد لبس درع أو سلاح أو جيرمنت أو حصان، يراه كل اللاعبين حولك فوراً، وعند الضغط على معاينة لاعب (`Observe`) تظهر كل معداته وسوكتاته والبلس والدم الإضافي.
4. **رمي والتقاط الأيتمات والفلوس على الأرض (`MapItem.cs` & `MsgMapItem.cs`):** مع حماية ملكية الدروب لمدة 30 ثانية واختفاء تلقائي بعد 60 ثانية لمنع تراكم الأيتمات في المابات.
5. **التطوير الرسمي الكامل:**
   * رفع الجودة بالدراجون بول (`Normal -> Refined -> Unique -> Elite -> Super`) مع فرصة فتح سوكت حظ!
   * رفع لفل الأيتم بالميتور (`Meteor` / `MeteorTear`) مع فرصة فتح سوكت حظ!
   * تركيب وخلع الـ Gems في السوكتات (`MsgGemEmbed.cs`) شاملاً جواهر الرعد والمجد للمروحة والبرج (`Thunder / Glory Gems`).
   * التطوير من `+1` إلى `+12` بالحجارة أو الأيتمات بلس (`MsgDataArray.cs`) + دمج الحصنة وخلط ألوان الحصان RGB بنسبة كونكر الرسمية (`90% + 10%`)!
   * إضافة دم إضافي للأيتم بالـ Gems (`Enchant HP` حتى `255` بـ Super Dragon Gem).
   * شحن سوكتات التليزمان (المروحة والبرج) بالتضحية بالأيتمات أو بالكبس.
   * قفل الأيتمات لحمايتها وفك القفل بمهلة 5 أيام رسمية (`MsgEquipLock.cs`).
   * حساب الـ **Battle Power** الرسمي للمعدات واللفلات والريبورن.
6. **محرك سكريبتات الأيتمات بـ C# (`ItemScriptEngine.cs`):** لتشغيل الجرعات، لفافات المدن، لفافات الميتور والدراجون بول، كرات الخبرة، صبغات الشعر، وشنط الكبس، وإضافة أي أيتم جديد في 10 سطور فقط!

### 2. تعديل أسعار الأيتمات أو إضافتها للشوبات والمول (Shopping Mall)
* **الملف المسؤول عن القراءة:** `src/Comet.Game/World/Managers/ItemManager.cs`
* **المعالجة وقت الشراء والبيع:** `src/Comet.Game/Packets/MsgItem.cs` (عند `ShopPurchase` و `ShopSell`).
* **كيف تعدّل الأسعار أو الشوبات بأسهل طريقة بدون كتابة كود؟**
  1. ادخل بحساب GM واكتب في الشات مرّة واحدة فقط:
     ```text
     /syncitemsdb
     ```
     سيقوم هذا الأمر بنسخ كل أيتمات الكلينت والبلس والشوبات إلى قاعدة بياناتك `comet.game` داخل جداول `cq_itemtype` و `cq_itemaddition` و `cq_goods`!
  2. افتح برنامج **Navicat** أو **HeidiSQL**:
     * **لتغيير سعر أي أيتم بالفضة أو الكبس:** افتح جدول `cq_itemtype`، ابحث عن رقم الأيتم في عمود `id`، وعدّل عمود `price` (سعر الفضة) أو عمود `emoney_price` (سعر الكبس CPs).
     * **لإضافة أيتم لشوب معين أو للمول:** افتح جدول `cq_goods` وأضف صفاً جديداً:
       * `ownerid`: رقم الشوب (مثلاً `2888` هو شوب الكبس Shopping Mall!).
       * `itemtype`: رقم الأيتم المراد بيعه.
       * `moneytype`: ضع `0` للفضة أو `1` للكبس (CPs).
       * *(ملاحظة مهمة: إذا أضفت أيتماً جديداً لشوب غير موجود أصلاً في الكلينت، يجب أيضاً إضافة رقمه في ملف `ini/Shop.dat` داخل الكلينت ليظهر للاعب في النافذة).*

### 3. تعديل نسب نجاح الميتور والدراجون بول وفرصة فتح السوكت
* **الملف المسؤول:** `src/Comet.Game/Packets/MsgItem.cs`
* **أين تجدها وكيف تعدّلها؟**
  1. **فرصة فتح سوكت بالدراجون بول (`EquipmentImprove`):**
     ابحث في `MsgItem.cs` عن `case ItemActionType.EquipmentImprove:` ستجد:
     ```csharp
     int roll = await Kernel.NextAsync(0, 1000);
     if (target.SocketOne == Item.SocketGem.NoSocket && roll < 15) // <-- 15 من 1000 = 1.5% للسوكيت الأول
         target.SocketOne = Item.SocketGem.EmptySocket;
     else if (target.SocketOne != Item.SocketGem.NoSocket && target.SocketTwo == Item.SocketGem.NoSocket && roll < 3) // <-- 0.3% للسوكيت الثاني
         target.SocketTwo = Item.SocketGem.EmptySocket;
     ```
     كلما رفعت رقم `15` أو `3` (من أصل `1000`) زادت نسبة فتح السوكت!
  2. **نسب نجاح الميتور حسب لفل الأيتم (`EquipmentLevelUp`):**
     تحتها مباشرة عند `case ItemActionType.EquipmentLevelUp:` ستجد:
     ```csharp
     int successChance = reqLvl switch
     {
         < 50 => 100, // تحت لفل 50 نجاح 100%
         < 70 => 85,  // تحت لفل 70 نجاح 85%
         < 90 => 70,  // تحت لفل 90 نجاح 70%
         < 110 => 50, // تحت لفل 110 نجاح 50%
         _ => 35      // لفل 110 فأعلى نجاح 35%
     };
     ```
     غيّر الأرقام كما تحب (من `1` إلى `100`).

### 4. تعديل نقاط التطوير من `+1` إلى `+12` (`Composition`)
* **الملف المسؤول:** `src/Comet.Game/Packets/MsgDataArray.cs`
* **الدالة:** `GetRequiredComposePoints` في آخر الملف:
  ```csharp
  public static ushort GetRequiredComposePoints(uint currentPlus, bool isSteed) =>
      currentPlus switch
      {
          0 => 20,    // من +0 إلى +1 يحتاج 20 نقطة
          1 => 20,    // من +1 إلى +2 يحتاج 20 نقطة
          2 => isSteed ? (ushort)90 : (ushort)80,
          3 => 240,
          4 => 720,
          5 => 2160,
          6 => 6480,
          7 => 19440,
          8 => 58320, // من +8 إلى +9
          9 => 2700,  // من +9 إلى +10
          10 => 5500, // من +10 إلى +11
          11 => 9000, // من +11 إلى +12
          _ => 0
      };
  ```
  حالياً مضبوطة 100% على أرقام كونكر الرسمية. لو أردت مستقبلاً تسهيل البلس في سيرفرك، فقط قلّل هذه الأرقام!

### 6. كيف تضيف صندوق هدايا أو سكرول أو شنطة كبس جديدة بنفسك؟ (`ItemScriptEngine.cs`)
* **الملف المسؤول:** `src/Comet.Game/World/Managers/ItemScriptEngine.cs`
* صممنا النظام بحيث لا تحتاج لتعقيدات `cq_action` نهائياً! لو أردت مثلاً عمل صندوق رقمه `720999` يعطي اللاعب مليون فضة و `500` كبس عند الضغط عليه كليك يمين، فقط افتح `ItemScriptEngine.cs` وأضف في آخره:
  ```csharp
  [ItemScript(720999)] // <-- ضع هنا رقم الأيتم
  public sealed class MyCustomGiftBox : IItemScript
  {
      public async Task<bool> OnUseAsync(Character user, Item item)
      {
          if (!await user.UserPackage.SpendItemAsync(item, 1))
              return false;

          await user.AwardSilverAsync(1_000_000);
          await user.AwardConquerPointsAsync(500);
          await user.SendTalkAsync("مبروك! حصلت على مليون فضة و 500 كبس!");
          return true;
      }
  }
  ```
  السيرفر يكتشف الكلاس تلقائياً عند التشغيل بفضل `[ItemScript(...)]` بدون أن تحتاج لتسجيله في أي ملف آخر!

### 7. أوامر الـ GM الجديدة الخاصة بالأيتمات
تمت إضافتها في `CommandManager.cs`:
* `/item <رقم_أو_اسم_الأيتم> [بلس] [دمج_بلس] [دم_إضافي] [جوهرة1] [جوهرة2] [العدد]`
  * مثال بالاسم: `/item DragonBall 0 0 0 0 0 5` (ينشئ 5 دراجون بول في شنطتك).
  * مثال لمعدات كاملة: `/item Katana 12 7 255 13 13` (ينشئ كاتانا +12 دمج -7 دم 255 وسوكتين سوبر دراجون جيم `13`!).
* `/clearinv`: يمسح كل الأيتمات غير المقفولة من الشنطة لتسهيل التجربة.
* `/syncitemsdb`: ينسخ كل أيتمات الكلينت والبلس والشوبات إلى جداول MySQL بضغطة واحدة.
