# دليل تأمين سيرفر `Mystic-Realms` الشامل ورفع الكلينت للاعبين (`[Build v5.6]`)

هذا الملف يشرح لك — خطوة بخطوة وكأنك لم تبرمج من قبل — **كل طبقات الحماية والاتصال** التي تم بناؤها وتقفيلها في تحديث **`[Build v5.6]`** لحماية سيرفرك واقتصاد اللعبة من أي سرقة أو اختراق أو تدبيل (Dupe)، بالإضافة إلى **الطريقة الصحيحة لرفع الكلينت للاعبين** سواء للتجربة مع أصدقائك أو عند الانتقال إلى سيرفر استضافة عالمي (**VPS**).

---

## أولاً: ماذا تم تأمينه وإصلاحه برمجياً في `[Build v5.6]`؟

### 1. إغلاق أخطر ثغرة اختراق في سورس Comet الخام (منفذ `RPC 5817`)
* **المشكلة التي كانت موجودة في Comet الخام:** كان ملف `Comet.Game.config` يفتح جسر الاتصال الداخلي (`RpcNetwork`) على `0.0.0.0:5817` (أي للإنترنت بالكامل!) بدون باسورد أو تحقق من الـ IP، مما يسمح لأي هكر يفحص بورت `5817` على الـ VPS بإرسال أمر `TransferAuth` ومنح نفسه رتبة **Admin (`AuthorityID = 5`)** والدخول بأي حساب!
* **الحماية المطبّقة الآن:**
  1. تم قفل `RpcNetwork.IPAddress` افتراضياً على **`127.0.0.1`** (داخلي على نفس الجهاز فقط ويستحيل الوصول إليه من الإنترنت).
  2. تم تزويد كلاس `src/Comet.Network/RPC/RpcServerListener.cs` بقائمة بيضاء صارمة (`AllowedClientIPs`) ترفض فوراً أي اتصال غريب وتطبع تحذيراً أمنياً `[SECURITY] Blocked unauthorized RPC connection attempt`.
  3. تم حذف الحساب التجريبي الافتراضي القديم (`Spirited`) من ملف `sql/comet.account.sql` حتى تبدأ قاعدة البيانات نظيفة 100% بدون أي حسابات مسبقة.

### 2. تأمين الاتصال للاعبين في مصر والسايبرات وشبكات الـ VPS (`CGNAT` + `StrictAuthPass` + `Graceful Disconnect`)
* **حماية اللاعبين الشرعيين من الحظر الخاطئ (`TcpServerRegistry.cs` و `TcpServerListener.cs`):**
  * في مصر والدول العربية، يشترك عدة لاعبين في نفس الـ IP العام بسبب نظام `CGNAT` في شركات الإنترنت (أو في السايبرات أو عند فتح 3 كلينتات معاً + فحص `ConquerLoader` لحالة السيرفر).
  * السورس الخام كان يحظر الـ IP لمدة **15 دقيقة صامتة** بعد 10 اتصالات! تم ضبط الحماية الذكية لتسمح حتى **30 اتصالاً نشطاً** و**60 محاولة في الدقيقة** للـ IP الواحد، مع حظر مؤقت **دقيقتين فقط** لمهاجمي الـ Flood الحقيقيين واستثناء فحص السيرفر الداخلي `127.0.0.1`.
* **إغلاق آمن للمقابس (`Graceful Socket Shutdown` في `TcpServerActor.cs`):**
  * عند انتقال اللاعب من `Account Server (9960)` إلى `Game Server (5816)`، يتم إغلاق السوكت عبر `Shutdown(SocketShutdown.Both)` ثم `Close()` لضمان وصول باكت `MsgConnectEx` ذي الـ **32 بايت** كاملاً حتى لو كان إنترنت اللاعب بطيئاً أو بـ Ping مرتفع، ومنع تسريب فتحات `MaxConn` (`500` للأكاونت و`1000` للجيم).
* **تفعيل مطابقة الـ IP للتوكن (`StrictAuthPass: true` الذكي في `MsgConnect.cs`):**
  * يمنع أي شخص على الإنترنت من سرقة أو تخمين توكن دخول لاعب آخر، وفي نفس الوقت يتعرف تلقائياً على كروت الشبكة المحلية لجهازك أنت (`127.0.0.1` / `192.168.x.x` / `25.x.x.x`) فلا يعطّل تجربتك المحلية أبداً!
* **دعم خوادم الـ Cloud VPS / الراوتر (`NAT Mode` في `RealmsRepository.cs`):**
  * فحص `[SelfTest]` عند التشغيل يتعرف تلقائياً إن كان الـ IP العام للسيرفر مربوطاً مباشرة بكرت الشبكة أو خلف نظام `Cloud 1:1 NAT` (مثل AWS / Oracle / Router Port Forwarding).
* **حماية باسوردات الحسابات من التخمين (`Brute-Force Protection` في `MsgAccount.cs`):**
  * إذا حاول مخترق تجربة **6 باسوردات خاطئة** خلال 3 دقائق، يتم إيقاف محاولات ذلك الـ IP مؤقتاً لمدة 3 دقائق دون قفل حساب الأدمن نفسه من الـ IP الخاص بك!
* **إصلاح ظهور اسم الشخصية ومستوى الـ VIP في باتش 5187 (`MsgUserInfo.cs`):**
  * تصحيح البايت رقم `70` (`NameDisplayed = 1`) والبايت رقم `83` (`VIPLevel`) ليظهر اسم اللاعب فوق رأسه ورتبة الـ VIP فوراً وبشكل مطابق للـ Official 5187.

### 3. منع إسقاط السيرفر بالباكتات المفخخة (Anti-Crash / Anti-DoS)
* **`TcpServerListener.Splitting`:** رفض أي حزمة طولها أقل من `4` بايت أو أكبر من `1024` بايت على مستوى الشبكة قبل استهلاك الذاكرة.
* **`PacketProcessor.DequeueAsync`:** إحاطة معالج الحزم بـ `try/catch` معزول بحيث لو أرسل مخترق حزمة تالفة يتم طرده هو فقط دون توقف أي خيط معالجة (`Partition`) في السيرفر!
* **`Comet.Game/Server.cs` و `MsgAction.cs`:**
  * منع إرسال أي باكت لعب قبل تسجيل الدخول الفعلي عبر `MsgConnect`، ومنع إعادة إرسال `MsgConnect` أو باكتات التحميل الأولية (`MsgAction 74/75/76/77/78`) ببرامج الباكتات (مثل WPE Pro) أثناء اللعب!

### 4. سد ثغرات الدوبل والنصب والسرقة في الاقتصاد (Anti-Dupe & Anti-Scam)
* **التجارة (`Trade.cs`) والبوثات (`BoothNpc.cs`):**
  * حماية حسابية بـ `ulong` ضد تجاوز حد الـ **2 مليار سيلفر** أو **2 مليار سي بي (`MAX_CONQUER_POINTS`)** وتصحيح `SpendSilverAsync` / `SpendConquerPointsAsync` لترفض القيم السالبة أو الصفرية قطعياً.
  * منع تحريك أو رمي أو بيع أو تقسيم أو تطوير أو تخزين أي أيتم أثناء فتح نافذة التجارة (`user.Trade != null`) أو أثناء عرضه في البوث (`IsItemLockedInBooth`).
  * **منع دوبل فصل السيرفر (`Crash-Dupe`):** حفظ فوري (`SaveAsync`) لكلا الطرفين في قاعدة البيانات لحظة إتمام أي تجارة أو شراء من البوث.
  * **تصحيح تركيب الحصان +12 (`MsgDataArray.cs`):** سحب الحصان الفرعي أولاً قبل إضافة النقاط لمنع تكرار نفس الـ ID داخل مصفوفة الحزمة.
* **المخازن والشوبات (`MsgPackage.cs` و `MsgItem.cs`):**
  * قفل المخازن على الـ **7 مخازن الرسمية فقط** (`8, 44, 10011, 10012, 10027, 10028, 4101`) والتحقق من المسافة الفعلية للـ NPC (أو مستوى الـ VIP)، والتحقق من القرب من الـ NPC عند البيع والشراء من المحلات.
* **فصل صلاحيات الطاقم وسجل المراقبة السري (`CommandManager.cs` + `Character.cs`):**
  * لم يعد الاسم المنتهي بـ `[GM]` يمنح أي صلاحية أبداً؛ العبرة **فقط** برقم `AuthorityID` في جدول `account` بقاعدة البيانات:
    * `1` = لاعب عادي (`Player`).
    * `2` = مشرف شات (`Moderator`) -> مسموح له فقط `/goto` و `/kick`.
    * `3` = جي إم متابعة (`Game Manager`) -> مسموح له التنقل ومساعدة اللاعبين والإعلانات (`/goto`, `/bring`, `/kick`, `/bc`, `/heal`, `/revive`, `/chgmap`) **وممنوع تماماً** من توليد أي أيتم أو سي بي أو سيلفر أو لفل!
    * `4` و `5` = مدير المشروع / المالك (`PM` / `Administrator`) -> الصلاحية الكاملة.
    * لا يمكن لأي مشرف أو جي إم استخدام `/kick` أو `/bring` على رتبة مساوية له أو أعلى منه!
  * **ملفات المراقبة التلقائية (لمعرفة كل صغيرة وكبيرة تحصل في سيرفرك):**
    * `Logs/GmAudit/`: يسجل كل أمر يكتبه أي شخص من الطاقم بالتاريخ والثانية ورقم الحساب والـ IP والإحداثيات.
    * `Logs/Economy/`: يسجل كل عملية تجارة (`Trade`) أو بيع في السوق (`Booth`) بتفاصيل السيلفر والـ CPs والأيتمات.

## ثانياً: أماكن التعديل اليدوي في الكود (شرح مبسط للمبتدئين)

1. **تعديل حدود حماية الاتصال (عدد الكلينتات المسموح فتحها من نفس الـ IP):**
   * افتح الملف: `src/Comet.Network/Sockets/TcpServerRegistry.cs` (حوالي السطر `36`):
     * `banMinutes = 2`: مدة الحظر المؤقت بالدقائق عند محاولة عمل Flood.
     * `maxActiveConn = 30`: أقصى عدد نوافذ لعبة مفتوحة في نفس اللحظة من نفس الراوتر/الـ IP.
     * `maxAttemptsPerMinute = 60`: أقصى عدد محاولات اتصال في الدقيقة الواحدة.
2. **تعديل عدد محاولات الباسورد الخاطئة قبل القفل المؤقت:**
   * افتح الملف: `src/Comet.Account/Packets/MsgAccount.cs` (السطر `29`):
     * `MaxFailedPasswordAttempts = 6` (عدد المحاولات الخاطئة).
     * `FailedAttemptWindow = TimeSpan.FromMinutes(3)` (مدة الانتظار بالدقائق).
3. **إعطاء رتبة Admin لنفسك أو GM لمساعدك من قاعدة البيانات:**
   * افتح `phpMyAdmin` -> قاعدة بيانات `comet.account` -> جدول `account` -> عدّل عمود `AuthorityID` لحسابك إلى **`5`** (`Administrator`).
4. **تعديل الأوامر المسموحة للـ GM العادي مقابل الـ Admin:**
   * افتح الملف: `src/Comet.Game/World/Managers/CommandManager.cs` (حوالي السطر `76`) عند قائمة `isEconomyOrPowerCmd`.

## ثالثاً: كيف ترفع السيرفر والكلينت للاعبين الخارجيين بدون أي خطأ اتصال؟

### الحالة (أ): التجربة الآن على جهازك أنت أو مع أصدقائك عبر Hamachi
1. تأكد أن كلاً من `Comet.Account.config` و `Comet.Game.config` فيهما:
   * في `Comet.Account.config`: `"IPAddress": "0.0.0.0"`, `"Port": 9960`.
   * في `Comet.Game.config`: `"GameNetwork"` على `"0.0.0.0"` وبورت `5816`، و `"RpcNetwork"` على **`"127.0.0.1"`** وبورت `5817`، و `"StrictAuthPass": true`.
2. في جدول `realm` داخل قاعدة بيانات `comet.account`:
   * `Name` = `Mystic-Realms`
   * `GameIPAddress` = `25.21.212.130` (عنوان هاماشي الخاص بك)
   * `RpcIPAddress` = `127.0.0.1`
   * `GamePort` = `5816` و `RpcPort` = `5817`.
3. أي صديق يدخل معك نفس غرفة الـ Hamachi ويضع في اللانشر `25.21.212.130` سيتصل بالسيرفر ويدخل اللعبة فوراً!

### الحالة (ب): عند شراء استضافة `Windows VPS` وفتح السيرفر لكل الناس على الإنترنت 🌐
عند نقل السيرفر إلى **Windows VPS** له **Public IP ثابت** (مثلاً لنفترض أن الـ IP العام للـ VPS هو `185.100.200.50`):

1. **إعداد جدول `realm` في قاعدة بيانات الـ VPS:**
   ```sql
   UPDATE `realm`
   SET `Name` = 'Mystic-Realms',
       `GameIPAddress` = '185.100.200.50',
       `RpcIPAddress` = '127.0.0.1',
       `GamePort` = 5816,
       `RpcPort` = 5817
   WHERE `RealmID` = 1;
   ```
2. **قواعد جدار الحماية (Windows Firewall / لوحة تحكم الـ VPS) — مهم جداً لحمايتك من الاختراق!**
   * ✅ **افتح للإنترنت هذين المنفذين فقط (TCP Inbound):**
     * البورت **`9960`** (تسجيل الدخول — `Comet.Account.exe`).
     * البورت **`5816`** (دخول عالم اللعبة — `Comet.Game.exe`).
   * ⛔ **إياك ثم إياك فتح هذه المنافذ للإنترنت أبداً:**
     * البورت **`3306`** (قاعدة بيانات MySQL — اتركه `127.0.0.1` داخلياً فقط وباسورد قوي لـ `root` غير الأرقام السهلة!).
     * البورت **`5817`** (جسر الـ RPC الداخلي — مربوط الآن تلقائياً على `127.0.0.1`).
3. **تجهيز مجلد الكلينت قبل ضغطه (`.zip` / `.rar`) ورفعه للاعبين للتحميل:**
   * ضع عنوان الـ VPS العام (`185.100.200.50`) في إعداد الاتصال (`LoginHost = 185.100.200.50`, `GameHost = 185.100.200.50`, `LoginPort = 9960`, `GamePort = 5816`, `ServerName = Mystic-Realms`).
   * **لقفل إعدادات `ConquerLoader` حتى لا يراها أو يغيّرها اللاعبون:** يمكنك استخدام خاصية تشفير الإعداد في اللودر أو استخدام **`DragonLauncher`** / **`Comet.AutoPatcher`** الموجودين داخل مجلد `tools/` في السورس بحيث يفتح اللاعب الأوتوباتشر ويضغط **Play** مباشرة دون وجود زر Settings!
   * تأكد من عدم وجود أي ملفات تخص السيرفر أو قواعد البيانات داخل مجلد الكلينت قبل ضغطه ورفعه على MediaFire / Google Drive / Mega.
