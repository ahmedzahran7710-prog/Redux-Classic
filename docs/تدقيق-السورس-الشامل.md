# تدقيق شامل لسورس Redux 5065

**المشروع:** Redux — محاكاة سيرفر Conquer Online إصدار 5065 (الأصل: Pro4Never).
**النسخة المفحوصة:** `conquer-online/redux` @ `main` (آخر تحديث 2023-08-23) — نسخة مطابقة للفورك `ahmedzahran7710-prog/redux`.
**طريقة المراجعة:** قراءة كود ساكنة (static review) لـ 392 ملف C#، منها 360 داخل `Redux.csproj`.
**التاريخ:** 2026-10-22.

> **حدود مهمة:** لم يتم بناء السورس، ولم يتم تشغيله، ولم تُجرَّب أي ثغرة عمليًا. أرقام الأسطر من النسخة الحالية في هذا المستودع. أي إصلاح لازم يتجرب مع عميل 5065 حقيقي قبل الدمج.

### 🔴 C-2 — مفيش حد لمحاولات الدخول

### 🟠 H-4 — تقسيم الحزم (الباج المؤكد في `GameServer.cs`)

**الملف:** `Network/GameServer.cs:78-105`

```csharp
var offset = 0;
while (offset < buffer.Length)
{
    var size = *((ushort*)(ptr + offset)) + 8;
    var type = *((ushort*)(ptr + offset + 2));

    if (size < buffer.Length)            // ❌ المفروض: size < buffer.Length - offset
    {
        var sub = new byte[size];
        fixed (byte* pSub = sub)
        {
            MSVCRT.memcpy(pSub, ptr + offset, size);
            ProcessPacket(user, pSub, sub, type);
        }
    }
    else if (size > buffer.Length)       // ❌ المفروض: size > buffer.Length - offset
    { user.Disconnect(); break; }
    else { ProcessPacket(user, ptr, buffer, type); }  // ❌ لو offset > 0 بيقرأ من أول البافر

    offset += size;
}
```

**الأثر:** لما يوصل أكتر من باكت في نفس قراءة TCP (شائع)، الباكت الأخير بيتحسب حجمه «أقل من البافر» فيتم نسخ بايتات من **بعد نهاية البيانات**، أو يتم فصل اللاعب غلط، أو تبدأ المعالجة من `ptr` بدل `ptr + offset`.

**الإصلاح المقترح (يحتاج اختبار حمل حقيقي):**

```csharp
while (buffer.Length - offset >= 4)
{
    var size   = *((ushort*)(ptr + offset)) + 8;
    var type   = *((ushort*)(ptr + offset + 2));
    var remain = buffer.Length - offset;

    if (size < 8) { user.Disconnect(); break; }

    if (size < remain)
    {
        var sub = new byte[size];
        fixed (byte* pSub = sub)
        {
            MSVCRT.memcpy(pSub, ptr + offset, size);
            ProcessPacket(user, pSub, sub, type);
        }
    }
    else if (size > remain) { user.Disconnect(); break; }
    else { ProcessPacket(user, ptr + offset, /* … */, type); }

    offset += size;
}
```

### 🟠 H-5 — كل معالجات الحزم بتفترض طول ثابت

**النطاق:** `Redux/Packets/Game/*.cs` (46 ملف) + `ProcessPacket` في `Network/GameServer.cs:135-169`

## 7) ما لم يتم التحقق منه

- **البناء:** لم يُجرَّب `msbuild` ولا `NuGet restore`.
- **التشغيل:** لم يتم تشغيل السيرفر ولا العميل 5065.
- **الاختبار الأمني:** كل النتائج من مراجعة كود ساكنة، مفيش exploit عملي.
- **قاعدة البيانات:** لم تُستورد، ولم تُفحص الجداول غير `accounts`/`items`.
- **الأنظمة الكاملة:** `CombatManager` (1205 سطر) و`DropManager` و`GuildManager` و`NobilityManager` و`PetAI` اتقرأوا قراءة سطحية — محتاجين جولة تانية بعد ما السيرفر يشتغل.
- **العميل:** أي تعديل في الشبكة/المصادقة لازم يتجرب مع عميل 5065 حقيقي.
