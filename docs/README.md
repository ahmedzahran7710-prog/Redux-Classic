## ملخص سريع

- **حجم السورس:** 392 ملف C# (360 داخل المشروع) / 9.2 ميجا بدون `bin/obj`.
- **أخطر 4 حاجات:** باسوردات نص صريح (C-1)، مفيش حد لمحاولات الدخول (C-2)، قراءة خارج البافر في تقسيم الحزم (H-4)، والتقاط عناصر من أي مكان في الخريطة (H-6).
- **أهم تصحيح للكلاسيك:** `EXP_RATE = 5` — السورس مش 1x زي الأصل.
- **الوضع القانوني:** TQ صرّحت إنها مش بتسمح بسيرفرات خاصة، والأصول ملك NetDragon. راجع المستند قبل أي نشر.
