# Redux-Classic

نسخة عمل من سورس **Conquer Online 5065** (مشروع Redux الأصلي من Pro4Never)، مع تدقيق وتوثيق بالعربي.

> ⚠️ **تنبيه:** المشروع ده دراسة/تعلّم. حقوق اللعبة والعميل والأصول ملك **NetDragon / TQ Digital**. تشغيل سيرفر عام أو توزيع ملفات العميل فيه مخاطرة قانونية. اقرأ [`docs/كونكر-كلاسيك-الرسمي-والقوانين.md`](docs/كونكر-كلاسيك-الرسمي-والقوانين.md) قبل أي نشر.

## البدء السريع (Windows)

1. ثبّت **Visual Studio 2022** مع workload «.NET desktop development».
2. ثبّت **MariaDB 10.11** (موصى به) أو MySQL 5.7 — **مش MySQL 8** (سبب: `MySql.Data 6.10.9`).
3. استورد `Nov_16_Backup.sql` في قاعدة اسمها `redux`.
4. افتح `Redux.sln` → `Restore NuGet Packages` → Build.
5. شغّل السيرفر، وأدخل IP/اسم السيرفر/بيانات القاعدة في نموذج الإعداد الأول.
6. ثبّت عميل **5065** + `ConquerLoader`، وعدّل الـ IP في `LoaderSet.ini`.

> ملاحظة: `127.0.0.1` مش هيعمل — استخدم IP الشبكة أو IP خارجي.


## ملفات التشغيل (الخرائط)

مجلد `Redux/bin/` (فيه `map/tinymap` بحجم ~82 ميجا) **مش موجود في المستودع** لأنه نسخة مكررة من أصول اللعبة، ومش منطقي نحط 163 ميجا نسختين في Git.

قبل التشغيل:

1. نزّل نسخة السورس الأصلية: `git clone https://github.com/ahmedzahran7710-prog/redux.git`
2. انسخ `redux/Redux/bin/Release/*` إلى `Redux/bin/Release/` في المشروع.
3. أو ابني المشروع وانسخ مجلد `map` من أي نسخة عندك.
